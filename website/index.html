功能特性

内核尽量薄，一切增强皆插件。以下为开箱即用的内核能力。

🔐

安全账号体系

注册 / 登录 / 找回密码，bcrypt 散列，JWT 带 token_version 支持主动失效，封禁强制全端下线，自定义头像。

实时消息管道

WebSocket 心跳 + 指数退避重连，已读回执、2 分钟撤回、"对方正在输入"、在线状态，断线重连自动补齐数据。

💬

单聊群聊同构

统一会话模型：单聊幂等复用，群聊建 / 搜 / 加 / 退、踢人与群主转让，会话列表未读红点与分组筛选。

🧩

插件系统

沙箱 iframe 运行、描述式 UI 白名单渲染、权限清单确认、同名上传即升级，站长可全局下架任意插件。

🛠️

站长后台

用户封禁 / 解封 / 随机重置密码，插件按名称聚合视图与全局下架，构建版本信息一目了然。

📦

运维友好

结构化日志按天轮转，三档限流（Redis 可选共享配额），健康检查与版本接口，一条命令从 Gitee 升级。

插件系统：写一个 JS 文件，扩展整个网站

每个插件是一个 ≤1MB 的 JS 文件，运行在 sandbox iframe 中，通过 postMessage 与主站通信，UI 一律以描述式 JSON 交由白名单组件渲染。

安全模型

  • 插件不接触 DOM、拿不到 JWT、读不到主站存储
  • 安装时展示权限清单，用户确认后才启用
  • 网络请求经主站桥接，仅放行 allowedHosts 白名单域名
  • URL 安装有 SSRF 防护：拒绝私网 / 回环 / 非 http(s)

描述式 UI：8 个白名单组件

textimagebutton inputcardlist dividerlink

白名单外的组件与 javascript: 链接一律拒绝渲染——插件拿不到任意 HTML 注入能力。

weather.plugin.js
/* {
  "name": "weather-demo",
  "version": "1.0.0",
  "permissions": ["message:read", "message:send",
                  "message:render", "ui:panel", "storage"],
  "allowedHosts": ["*.openweathermap.org"]
} */
function __mcActivate(api) {
  // 注册自定义消息类型：主站在气泡内渲染
  api.registerMessageRenderer('weather', (p) => ({
    title: '',
    body: [{ component: 'text',
             props: { content: p.city + ' ' + p.sky + ' ' + p.temp + '°C' } }],
  }));

  // 侧边栏面板（描述式 UI）
  api.addSidePanel({
    title: 'Weather',
    body: [
      { component: 'text', props: { content: 'Hangzhou · Sunny 22°C' } },
      { component: 'button', props: { text: 'Refresh' }, action: 'refresh' },
    ],
  });
}
API 作用 所需权限
api.on(event, fn)订阅 message:new / recall / presence / conv:open / ui:actionmessage:read
api.send(convId, payload, msgType?)发消息，对象自动 JSON 序列化message:send
api.registerMessageRenderer(type, fn)自定义消息类型 → UI 描述message:render
api.addSidePanel(desc)提交侧边栏面板 UI 描述ui:panel
api.storage.get / set每插件独立命名空间存储（单值 ≤64KB）storage
api.request(url, opts?)主站代为 fetch，仅放行 allowedHosts 域名net
api.theme.apply(cssVars)修改 TDesign 主题令牌，全站即时换肤ui:theme

快速开始

两个终端、四条命令，跑起一个完整的 ModernChat。首个注册的账号自动成为站长。

git clone https://gitee.com/Sun-Si-Cheng/modern-chat-new.git
cd modern-chat-new
docker compose up -d --build            # MySQL 8 + backend :8080，首次启动自动建表
cd web && npm install && npm run dev    # frontend :5173
# backend：自备 MySQL 8.0
cd server
cp .env.example .env                    # DB_DSN + JWT_SECRET
go run ./cmd/server                     # :8080

# frontend
cd ../web
npm install
npm run dev                             # :5173，已代理 /api 与 /ws
curl http://127.0.0.1:8080/api/health   # {"status":"ok"}
curl http://127.0.0.1:8080/api/version  # {version, commit, buildTime}

# 打开 http://localhost:5173 → 注册首个账号（自动成为站长）
# 上传 plugins/examples/weather.plugin.js 体验插件系统
